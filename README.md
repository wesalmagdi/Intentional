# Intentional

Monorepo for Intentional, an app for deliberate, focused living.

## Structure

| Path | Purpose |
| ---- | ------- |
| `apps/mobile` | Mobile application |
| `packages/domain` | Core domain logic |
| `packages/database` | Data layer / persistence |
| `packages/ui` | Shared UI components |
| `packages/validation` | Validation rules |
| `tests` | End-to-end and integration tests |
| `docs` | Product, UX, and architecture docs |

## Getting started

```sh
pnpm install
```
